## Локальная проверка

Локальный URL: **http://localhost:8080/cash/cash-preview-20261012/**. Чтобы совпали project-site пути, извлеки ZIP в отдельный временный staging с дочерней папкой `cash`. Пример из папки с архивом:

```sh
cash_preview_stage=$(mktemp -d /tmp/cash-preview-stage.XXXXXX)
mkdir "$cash_preview_stage/cash"
unzip -q cash-preview-20261012.zip -d "$cash_preview_stage/cash"
python3 -m http.server 8080 --bind 127.0.0.1 --directory "$cash_preview_stage"
```

Этот static root содержит только отдельный preview. Текущий workspace и рабочий Cash серверу не передаются. Открывай точный путь со слешем или `/cash/cash-preview-20261012/index.html`; на другом пути учёт и регистрация service worker блокируются до чтения хранилища.

Первый запуск: пустая финансовая база; реальные интеграции отключены. Аналитика показывает неизвестные значения до явного выбора «Демо». Демо содержит только вымышленные события и не сохраняется в финансовую базу.

Все финансовые записи, тема, резервные копии и указатель последней копии используют префикс **`cash-preview-20261012:`**. Рабочие ключи `sf5`, `cash-theme` и `cash-backup-*` не читаются и не изменяются. Preview не перебирает ключи localStorage других приложений. Import/export и ручные записи относятся только к этому отдельному учёту; пользовательский JSON-импорт может содержать частные данные, поэтому не добавляй его в папку публикации.

Manifest `id`, `start_url`, `scope` и регистрация SW ограничены **`/cash/cash-preview-20261012/`**. Cache Storage использует собственный префикс `cash-preview-20261012:`; очистка удаляет только устаревшие кеши этого preview. Кешируется только оболочка, финансовые данные и API в кеш не попадают. Рабочая Cash PWA и её кеши не удаляются.

Последствия: новая PWA устанавливается отдельно как **Cash Preview**; финансовый учёт, тема и копии рабочего Cash сюда не переносятся автоматически. Данные preview останутся в этом браузере после закрытия; очистка браузерного хранилища удалит их. Preview не является дополнительной резервной копией рабочего учёта. Публикация, DNS, credentials и права не менялись.
